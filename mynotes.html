For most students, everything is kept together in a single Google Drive folder, with every file name starting with the date of the session it belongs to (YYYY-MM-DD). Sorting by name puts everything in chronological order.

  • Handwritten notes taken by me during class are in one file per session, titled YYYY-MM-DD ⭐ Class Notes.pdf.
  • Other materials from a session (worksheets, practice problems, answer keys, homework, images) are also named starting with that session's date, such as YYYY-MM-DD practice problems.
  • Some files, like textbooks or other reference materials used across many sessions, may appear without a date in the file name.
  • A subfolder titled teacher notes is sometimes present. These are files I use for my own preparation and may be ignored.
